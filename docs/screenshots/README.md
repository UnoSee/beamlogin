# Screenshots

The images in [`docs/images`](../images) are generated by the scripts in this folder. Regenerate
them after changing the terminal UI, the phone page or the diagram.

| File | What it makes |
|---|---|
| `Dockerfile` | An image with a terminal emulator (pyte), Pillow and headless Chromium |
| `capture.py` | Runs the real binary against [`tests/fake_claude`](../../tests/fake_claude) in a pseudo-terminal and screenshots the terminal and the phone page in each state |
| `compose.py` | Puts the phone screenshots into phone frames with captions, builds the hero image and sizes the terminal screens |
| `diagram.py` | Draws the "How it works" diagram in light and dark versions |

Everything runs against the stand-in Claude Code, so no real account is used. The screenshots
show the example address `192.168.0.10` and the example account `you@example.com`.

## Regenerate

Run these from the project root. You need Docker and a built binary in `dist/`.

```bash
docker build -t beamlogin-shots docs/screenshots
```

```bash
docker run --rm --hostname live-iso -v "$PWD/docs/screenshots:/work" -v "$PWD:/src:ro" -v "$PWD/dist/beamlogin-x86_64-linux:/bin/beamlogin:ro" beamlogin-shots sh -c "python3 /work/capture.py && python3 /work/compose.py && python3 /work/diagram.py"
```

```bash
cp docs/screenshots/final/*.png docs/images/
```

The run leaves raw captures in `docs/screenshots/out` and finished images in
`docs/screenshots/final`. Both are scratch output and can be deleted once the images are copied.
